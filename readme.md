🚖 NYC Taxi Fare Prediction System
A Machine Learning-powered web application that predicts NYC taxi fares based on trip details such as distance, duration, passenger count, pickup hour, pickup day, and pickup month.

🔗 Live Demo:
https://taxifare-ezrvebvh2s9zqczc6d53bs.streamlit.app/

📌 Project Overview
The NYC Taxi Fare Prediction System is designed to estimate taxi fares using historical trip patterns and machine learning techniques. Users can enter trip-related information through an interactive Streamlit interface and instantly receive a fare prediction.

This project demonstrates the complete machine learning workflow, including:

Data preprocessing
Feature engineering
Model training
Model evaluation
Model deployment
Interactive web application development

📊 Input Parameters
The model predicts fare based on:

Feature	Description
Trip Distance	Total distance travelled (miles)
Trip Duration	Duration of ride (minutes)
Passenger Count	Number of passengers
Pickup Hour	Hour of the trip
Pickup Day	Day of the month
Pickup Month	Month of the year
🚀 How to Run Locally
Clone Repository
git clone https://github.com/SKT-SAKET/taxifare.git
Navigate to Project Folder
cd taxifare
Install Dependencies
pip install -r requirements.txt
Run Application
streamlit run app.py
