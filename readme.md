Taxi Fare Prediction
A Machine Learning web application that predicts taxi fares using trip-related information. The project includes model training, preprocessing, and an interactive Streamlit interface for real-time predictions.

Features
Real-time fare prediction
Interactive Streamlit UI
End-to-end machine learning workflow
Easy deployment with Streamlit Cloud

Installation
Clone the repository:

git clone https://github.com/SKT-SAKET/taxifare.git
Install dependencies:

pip install -r requirements.txt
Run the application:

streamlit run app.py
